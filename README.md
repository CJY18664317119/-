为落实《中国教育现代化2035》中关于“实施国家教育数字化战略，深化大数据、人工智能等研发应用，开展‘人工智能+教育’行动”的指示，基于《义务教育课程方案和课程标准（2022年版）》对项目式学习的新需求，本团队针对学科教学中开展项目式学习（Project Based Learning，下文简称PBL）所面临的问题，为科学、信息技术与通用技术学科教师精心打造"REAL-4Ps智能教学设计平台"。针对教师在大单元教学设计中存在的"情境创设难、活动设计散、评价反馈弱"三大痛点，结合知识建构理论与REAL本真课堂模型，聚焦于项目情境设计、教学活动设计和资源与工具库功能，综合运用xx等多项人工智能领域前沿技术，助力教师高效搭建PBL环境，革新科学、信息技术与通用技术学科的项目式教学范式，构建AI赋能的PBL教学设计系统，提升开展PBL教学备课活动时的整体效率，缩短备课时间，提升项目设计科学性与教学过程严谨性，以此构建“教师-AI-学生”协同学习网络，形成可复制、可推广的智能化PBL区域推进模式。在未来，该平台将逐步横向拓展学科领域，挖掘多元受众，形成K12全学段全学科PBL支持体系；同时，纵向渗透师范院校教师教育课程，构建覆盖教师职业发展全周期的智能支持生态。
